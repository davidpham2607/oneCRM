# Introduction

<div v-pre>


This documentation explains how to install, configure, and use oneCRM on your own server or hosting account.

## What is oneCRM

oneCRM is a complete customer relationship management application for small businesses and freelancers.

## Next steps

1. Check that your server meets the [requirements](./requirements.md).
2. Follow the [installation guide](./installation.md), or the [Docker installation](./docker.md) guide.
3. Set up the [cron job](./cron.md). With Docker it already runs.
4. [Register the installation](./license.md) so it receives updates.
5. Complete the [initial setup](./setup.md).
6. Keep your installation current with [updates & patches](./update.md).

> [!NOTE]
> You are reading the oneCRM documentation for version 1.x.
