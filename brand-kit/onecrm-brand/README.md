# oneCRM Brand Kit V1.0
Bộ nhận diện vector dựng lại theo mẫu đã duyệt, không phải bản truy vết pixel tuyệt đối. Logo dùng path SVG và chữ Inter Bold chuyển thành outline, không cần font để hiển thị logo. Không kèm file font. 

- logos/: logo ngang, dọc, icon, đơn sắc, âm bản, đen.
- tokens.json: design tokens dùng chung.
- brand.css: CSS thuần và component cơ bản.
- tailwind.css: theme Tailwind CSS v4 (cần môi trường build Tailwind).
- index.html: trang preview tĩnh, mở trực tiếp trong trình duyệt sau khi giải nén.
- MASTER-PROMPT.md: prompt định vị, thiết kế, code, kiểm thử.

Quy chuẩn: logo ngang tối thiểu 120px; icon 16px; khoảng trống bằng 1/4 chiều rộng biểu tượng. Không đổi tỷ lệ hoặc màu logo ngoài các phiên bản cung cấp. Font giao diện Inter, nội dung Be Vietnam Pro; cần cài hoặc tự host font hợp pháp để hiển thị đúng. Logo chưa được tra cứu nhãn hiệu hoặc kiểm tra in ấn thực tế. Các tuyên bố sản phẩm cần chủ dự án xác nhận trước khi công bố.
