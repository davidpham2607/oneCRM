Here is a list of all changes made in version 1.0.6.

- Added ability to attach invoice attachments to email
- Added option to set invoice due after X days in options
- Added ability to copy invoice
- Added option to mark lead as lost
- Added option to mark lead as junk
- Added Bulk PDF exporter for invoices/estimates/payments
- Added ability to send customer SET PASSWORD LINK
- Added task relation - task can be related to invoice/estimate/contract/customer/expense/ticket/lead
- Added ability to mark task as public - anyone can view this task
- Added ability to mark lead as public - anyone can view this lead
- Added ability to add shipping details to invoice
- Added client map
- Added options in settings to choose what items to show in the calendar
- Added ability to upload multiple contract attachments
- Added ability to add custom field editor
- Improved tasks
- Added editor to tasks
- Added editor to tickets reply (only for admins)
- Changed the editor
- Added email sending option for tasks
- Added tasks email templates
- Added invoice shipping details
- Added lead status color - Will be also used in the kan ban
- [Added leads email integration - auto importing leads from email](/docs/classic/3.x/leads/leads-email-integration)
- Added google calendar integration - Possible options: Main calendar for all staff and calendar by department - if is set main calendar and calendar for department will be shown events from both calendars for this staff members.
- Separated invoice billing details
- Moved settings menu to left side
- Removed lead assigne required
- Improved surveys question save - autosave after focout
- Improved leads kan ban
- Changed ticket attachments primary key from attachmentid to id
- Improved table PDF export headers width
- Fixed notifications loading in my profile
- Fixed view by lead status
- Fixed zip invoices/estimates/payments
- Fixed invoice item delete error
- Fixed client side knowledge base show without login if checked was not showing
- Fixed <br /> tags on invoice items after multiple save
- UI Improvements
- Code Improvements
- Other small bugs fixed
