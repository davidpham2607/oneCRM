After 3 months of hard work oneCRM version 2.0.0 is released on 17th of May, this version is a major version and comes with a lot of enhancements in code and features. You can check the full changelog and upgrade guides by clicking [here](https://help.onecrm.example.com/version-2-0/)

Also, it’s worth mentioning that oneCRM version 2.0.0 comply with the new GDPR law that takes effect on 25th of May 2018, if you are not familiar with this, you should check our dedicated post for how oneCRM can help you comply with GDPR

To get familiar with all improvements in version 2.0.0, we will try to walk you through them in this article.

### Stripe Subscription Payments

Stripe subscription billing was one of the most requested and useful features over the years, we decided to implement this feature to help you bill your customers in a more faster way without you lifting a finger.

This feature is still in early stages and improvements may be available in future updates, more information about subscription payments can be found here

### Security Improvements

Security is key to any CRM or web-based application, we added 2 more security features that will help you to fight spam bots and crawlers, you can check our dedicated documentation article for applying security measures

If you haven’t read the article for applying security measures in oneCRM, you should.

### E-Signature for Estimates, Contracts and Proposals

Starting from version 2.0.0 customers will be able to sign estimates, contracts and proposals with our e-sign feature. For contracts this feature is enabled by default and there is no option to turn off, but if for proposals and estimates you haven’t enabled yet, navigate to Setup->Settings->E-Sign and enable the feature.

### Print Lead Information

An option to print lead information is added, this option will help you also to comply with the GDPR law . You can print the lead information directly from the lead modal, on the right side you will be able to see a print button.

### Upload files for task comment

Before version 2.0.0 there was no option to upload comment attachment while commenting on task, now you will be able to upload files during upload and also those files will be grouped inside the comment and also will be shown as global files for the task.

An additional option for this is added, to download all comment files in a zip.

### Tables Improvements

For the main tables that are most used in oneCRM, we’ve removed the last “Options” column to save space, integrating those options into the first column for a cleaner, more usable interface. Additionally, we’ve added a colored indicator to the table headers to quickly identify the current sorting order.

Moreover, there’s now an option under <strong>Setup → Settings → Misc → Tables</strong> allowing the system to remember your sorting preferences. For instance, if you sort tickets by the date created in ascending order, it will automatically apply this preference on subsequent visits.

Keep in mind that this option is per staff, each staff member will be able to adjust his tables to best fit their needs.

### Track if specific sent email are opened

This feature will help you to easily determine eq if contact opened the email when you send the invoice to the contact email.

Click here to read more about this feature

### Change task and lead status directly from the table (list view)

To make easier changing the status of lead and tasks, now you can change the status without even opening the lead or task, from the tables you can locate the status column and click on the arrow next to the status name.
