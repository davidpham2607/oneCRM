Below you will find some of the features added in version 2.2.0, the list above is just part of the improvements and changes, to check the full [changelog](/docs/classic/3.x/changelog/version-2-2-0) for version 2.2.0.

### Email Verification For Registered Customers

Starting from version 2.2.0, the customers that will register manually from the customers area into the portal, they will need to confirm their email address in order to access all the features in customers area, this feature will require properly configured [mail config](/docs/classic/3.x/email-config-and-templates/smtp-configuration) in Setup->Settings->Email.

### Custom Task Reminders

Now you can add any custom reminders for a specific task and a specific member at a specific date, if you open the task modal, on the right side you will be able to see a new reminders feature, you can use this feature to add custom reminders for yourself or your team.

### Google Drive Picker

The [Google Drive](/docs/classic/3.x/setup-and-configuration/google-configuration-features) feature was requested multiple times along with the Dropbox Chooser feature which already exists in oneCRM. We added the Google Drive Picker feature so you can insert Drive links directly to oneCRM and save space in your server.

### Import Items Feature

From version 2.2.0 you can import sales items to save some time creating items manually one by one, we also spend some time to improve the importing feature for leads and customers too and rewrote a bunch of code.

If you navigate to Sales->Items on the top left side you will be able to see a new button “IMPORT ITEMS”

### Informational message when customer exists

To get a little help for duplicate customers, when creating a new customer an informational message will be shown below the company name to show you that the customer already exists, you can either stop creating the customer or create the customer if you have your own reasons to add a duplicate customer.

### Subtract Tax Amount From Expense

You can use this option to subtract the total tax amount from the expense amount, useful when you entered the expense amount with tax included (tax inclusive). In the previous version if the tax was already included in the expense amount, you needed to perform the calculations manually to find the exact expense amount without tax, now you can do this with a single click.

For example, let’s assume that you want to add new expense in oneCRM of total $1500 but the $1500 expense amount is already with 10% tax applied, in this case, in previous versions you must subtract the 10% tax amount manually to get the amount without tax, now you can do this by single click.

After you check the checkbox **Subtract TAX total**, the expense amount will be $1363.64 with additional 10% tax and will give the total of $1500 with 10% tax included.

### Instamojo

[Instamojo](https://www.instamojo.com/) is added as a payment gateway, Instamojo is modern payment gateway which deserves to exists in the oneCRM available payment gateways list. More information about Instamojo can be found in Setup->Settings->Payment Gateways->Instamojo

### Ability to Print Expense and Ticket Message/Replies

Now you can easily print your expenses and ticket message/replies if it’s needed to keep track of them on paper.

### Timesheets Overview Improved

If you navigate in Reports->Timesheets Overview, you will be able to see that the timesheets overview filtering is quite improved, now you can filter timesheets per customer and multiple projects additionally.

This improvement can give you an overview for example, how much time you/staff member spend working for a specific customer/projects for a given period selected based on the filters.
