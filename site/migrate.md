# Bring your oneCRM Classic records into oneCRM

Classic Migrator is a free oneCRM module. Install it, point it at your oneCRM Classic folder or a SQL dump, and move the records your team works in every day.

1. 1
 

Install a fresh copy of oneCRM

 Create the first admin account on an empty installation. The wizard can continue if records already exist, but a clean install is the straightforward path.
2. 2
 

Download Classic Migrator  -  free

 Claim the module from this site, then install the ZIP from Settings → System → Modules. Open Settings → System → Classic migration.
3. 3
 

Point it at oneCRM Classic

 If Classic is still on the same server, paste the folder path. Otherwise upload a phpMyAdmin SQL dump. Attach the uploads folder now, or skip files and add them later.
4. 4
 

Review the report, then run

 The wizard lists what will move and what will not. Keep the page open while batches run. Close the tab and reopen the same page to resume. You can undo the import if you need to start over.

### Not imported

- Third-party oneCRM Classic modules, custom PHP, and themes
- Proposals, contracts, Stripe subscriptions, and estimate request forms
- Email settings, ticket mailbox passwords, and payment gateway keys
- The Classic editor media folder  -  copy it into public/media after import

### Set these up in oneCRM

- Appearance, navigation, AI provider keys, and e-invoicing
- Staff roles and permissions  -  review them after import
- Keep Classic Migrator installed until everyone has signed in once, old public links can be retired, and you no longer need Undo
- If oneCRM lives at a new address, ask your host to redirect the old Classic URL
